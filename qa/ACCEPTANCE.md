# 验收说明

## 素材与构建

旧单 HTML 中提取到 31 张忍者和 18 张秘卷。逐卡缩略图人工检查发现 26 张有明显边缘截断、邻卡横边或横向残片问题；其余卡面存在留黑和卡框比例不一致，统一替换以避免把旧版静态数值带入新版本。逐张记录见 `original-card-audit.json`，旧素材保留于 `assets/original/`。

新素材采用内置 imagegen 每张独立生成。PNG 原图保留；WebP 仅等比缩小和编码，不做卡册裁切。游戏中卡面使用 `object-fit: contain`，姓名、属性、威力和倍率独立排版。战斗、商店、持有秘卷、图鉴与详情共用同一个 ID 映射。构建脚本检查所有预期源图存在才生成正式 HTML。

## 规则验证

`engine-tests.cjs` 验证：

- 55 名忍者、36 张秘卷、30 场战斗、10 个不同 Boss 机制和 ID 唯一性。
- 25 个新增小队 / 宿命羁绊与 8 个特性规则。
- 33 张伤害类秘卷的效果，以及 3 张成长 / 经济秘卷。
- 预览计算无副作用、选择顺序改变结果、封印最多四张、不同 Boss 的伤害惩罚。
- 多层 Boss 不能被溢出伤害跳过，层间不误发战利品；章节奖励未选时不能继续。
- 神树锁牌、出击耗尽失败、失败清档、商店稀有度分章解锁、保存恢复。

## 浏览器验证

使用本机 Google Chrome，通过 Playwright 运行。桌面 1440×900、平板 768×1024、手机布局 390×844 / 360×800；另有 `isMobile + hasTouch` 的 390×844 触控模拟。均从 `file://` 打开，并将浏览器设为 offline。

测试涵盖首屏、八张手牌、五张选择、真实首战击破、预览与实际伤害一致、粒子与连锁词条 DOM、商店购买扣款、刷新恢复、继续远征、完整卡面详情、55 / 36 卡牌图鉴、十章地图、手机触控换手和章节奖励。

具体结果见 `browser-results.json` 和同目录 PNG 截图。移动端为浏览器模拟验收，未声称完成实体 iPhone / Android 或 Safari / Firefox 实机测试。

## 平衡与时长

`balance-results.json` 保存三种起始队伍、每种三个随机种子共九次完整模拟。策略在多个候选出牌顺序间比较伤害，并根据队伍为秘卷估值；这是强策略可达性测试，不是新玩家胜率预测。模拟完成 30 战，每局 45 次出击。

20–30 分钟为设计估算，依据 45 次以上出击、29 次商店和 9 次章节奖励的阅读 / 选择 / 结算时间；未做真人计时测试。为了保留原需求的夸张倍率，高阶秘卷叠加允许极高溢出伤害。单击数值在 JavaScript 最大安全整数处封顶，界面以万、亿、万亿显示。
