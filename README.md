# SHINOBI CASCADE / 忍界连锁

完整卡面与顺序连携版，2026-09-11。

在线游玩：[shinobi-cascade.powerbier.chatgpt.site](https://shinobi-cascade.powerbier.chatgpt.site/)

公开源码：[github.com/muxiaoqi007/shinobi-cascade](https://github.com/muxiaoqi007/shinobi-cascade)

双击 `dist/shinobi-cascade.html` 即可离线游玩，不需要服务器或安装依赖。推荐使用近期版本的 Chrome、Edge 或 Safari。浏览器若允许本地存储，会自动保存稳定战斗状态和商店进度；重新打开页面后点击“继续已保存的远征”。进度保存在当前浏览器与文件路径下，移动文件或更换浏览器不会自动迁移。

## 本版内容

- 55 名忍者：原有 31 名 + 24 名新忍者。
- 36 张秘卷 / 遗物：原有 18 张 + 18 张新增，全部有实际效果。
- 91 幅独立竖版卡面：每张单独调用内置 imagegen 生成，原有 49 张全部替换。无拼版裁切；卡名、属性、数值由界面渲染。
- 10 章、30 场战斗、8 种普通 / 精英战场规则和 10 种 Boss 规则。Boss 每层结界切换战场规则；前五章两层，后五章三层。
- 新增 10 个小队组合、15 个宿命组合、8 个血继 / 特性组合、2 个顺序组合。连携图鉴含原版规则摘要。
- 第七班、猪鹿蝶、砂隐三种 9 张起始队；可拖动结印轨道；候选卡伤害与新增组合预览；章节三选一奖励；队伍精简；卡牌放大；地图。
- 商店先按章节概率抽稀有度，再在对应稀有度中按队伍羁绊加权。已有唯一角色以三阶觉醒商品出现，不会加入第二张同名角色。
- 游戏随机数由远征种子驱动并随进度保存，可用 `?seed=数字` 重现；战斗、商店和音效偏好均保存在浏览器中。
- 手机和平板提供紧凑敌情 HUD，以及包含秘卷、构筑和战斗日志的 Bottom Sheet。
- 保留乘法连锁、WebAudio、出牌弹性、冲击粒子、浮动巨型数字、闪光震屏、动态镭射与鼠标倾斜。系统开启“减少动态效果”时降低动画。

## 操作与节奏

按顺序选择 1–5 张忍者，点击“结印出击”。顺序可触发风→火、水→雷、风↔雷等；支援 / 医疗→强攻、战术→控制同样有组合。点击卡牌会显示加入后的伤害增量；已选卡出现在结印轨道中，可拖动或使用左右箭头重排。未出击前可反复取消与重选，伤害预览不会消耗任何一次性效果。`Enter` 出击、`R` 换手、`1–8` 选牌、`Esc` 关闭弹窗。

每战默认 4 次出击；换手可重置不合适的手牌。每次胜利全队基础威力 +3，章节熟练度逐章乘以 1.42。秘卷同时持有上限 5；商店可出售、重掷、训练、招募，并花 3 両移除一张队伍卡（至少保留 8 张）。Boss 结界逐层击破，后续层目标为前一层的 1.75 倍；破层额外补充 1 次换手，但不补出击次数。

设计时长约 20–30 分钟：45 次以上出击（每次选择与结算约 18–24 秒）、29 次商店（约 12–18 秒）和 9 次章节奖励。熟悉构筑的玩家可以更快。自动模拟用于验证可达性，不等同于真人时长测试。

## 项目文件

- `original/`：从本机找回的旧版离线 HTML。
- `assets/original/`：从旧 HTML 无损提取的 49 张旧 WebP。
- `assets/generated/`：91 幅完整生成 PNG 源图，保留原分辨率。
- `assets/cards/`：运行时 WebP，等比缩小、无裁切。
- `assets/prompts/`、`assets/generation-jobs.json`：每一幅图的生成提示词。
- `assets/manifest.json`：角色 ID、源图、运行图、尺寸和 SHA-256 映射。
- `src/`：数据、扩展规则、游戏逻辑、样式、音效、HTML 模板。
- `build.py`：离线单文件构建脚本；正式构建遇到缺图即失败。
- `qa/`：逐卡审查、规则与浏览器测试、平衡模拟、截图和验收说明。
- `recovery/`：本轮恢复、扩充过程脚本与提取出的旧版源码。

原始卡册海报和上一版独立项目 ZIP 未在本机找到；本版从实际缓存的单 HTML 恢复源码和全部内嵌素材，旧文件原样保留。所有本轮生成素材和实现文件均随项目交付。

## 重建

需要 Python 3 和 Pillow：

```sh
python3 -m pip install Pillow
python3 build.py
```

构建结果为 `dist/shinobi-cascade.html`。所有图片以 Data URI 内嵌；无 CDN、在线字体、网络请求或外部音频。生成美术不需要在重建时重新调用模型。

规则测试与模拟需要 Node.js：

```sh
node qa/engine-tests.cjs
node qa/balance.cjs 3
```

浏览器测试需要 Playwright 和 Chrome。`qa/browser-tests.cjs` 默认使用本机 Chrome 路径；可按运行环境调整。测试钩子仅在初始化前显式设置 `window.__SHINOBI_TEST__` 时启用，交付 HTML 默认关闭。

本项目为非官方同人游戏，角色来自《火影忍者》；图片为本轮生成式美术，音效实时合成。无官方素材下载。
